# DevLane brand assets

Official monochrome DevLane logo assets.

## Files

- `devlane-logo-black.svg` — master horizontal vector logo.
- `devlane-logo-black.png` — transparent high-resolution horizontal PNG.
- `devlane-symbol-black.svg` — standalone DevLane symbol, vector.
- `devlane-symbol-black.png` — standalone symbol, transparent high-resolution PNG.
- `devlane-symbol-black-512.png` — square 512 px symbol for avatars/icons.
- `devlane-logo-black-16x9-4k.png` — 3840×2160 white-background presentation asset.
- `devlane-logo-black-16x9-transparent-4k.png` — 3840×2160 transparent presentation asset.

## Usage

Prefer SVG for websites, print and scalable UI. Use the transparent PNG versions for social profiles, documents, and apps that do not support SVG.
